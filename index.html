    Como rodar a interface web?

    Devido a restrições de segurança em file:// no Chrome, recomenda-se servir via HTTP:

    pnpm web → abre http://localhost:8080

    Alternativa manual: python3 -m http.server 8080 ou Chrome com --allow-file-access-from-files.
